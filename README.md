# ImgBB Image Upload Bot 🤖

A simple yet powerful Python bot to upload multiple images to ImgBB hosting service.

## Features ✨
- 📸 Batch upload multiple images
- 🔑 One-time API key setup
- 🖼️ Supports JPG, PNG, GIF, BMP, WEBP
- 📊 Progress tracking and summary
- 💾 Saves upload URLs to JSON
- 🗑️ Delete URLs provided for each upload
- 🔒 Secure API key storage

## Installation 🚀

### Local Setup
```bash
git clone https://github.com/YOUR_USERNAME/imgbb-upload-bot.git
cd imgbb-upload-bot
pip install -r requirements.txt
python imgbb_upload_bot.py
